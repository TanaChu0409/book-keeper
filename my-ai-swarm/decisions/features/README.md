## 📋 概述

此目錄存放 BookKeeper 專案中重要功能的實作記錄。每個記錄應包含：

- **功能概述** (Overview): 功能的目的與用途
- **技術選型** (Technology Choices): 使用的技術與框架
- **實作細節** (Implementation Details): 關鍵程式碼片段與邏輯
- **API 規格** (API Specification): 端點定義與範例
- **測試策略** (Testing Strategy): 如何驗證功能正確性
- **已知限制** (Known Limitations): 功能的限制與未來改進方向
